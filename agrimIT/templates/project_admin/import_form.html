Importar proyectos desde CSV
  1. Descargá la plantilla CSV (ya trae las columnas correctas).
  2. Completá una fila por proyecto. Solo tipo y cliente_id son obligatorios.
  3. El cliente_id es el ID interno de un cliente tuyo (ver la tabla de abajo).
  4. Guardá el archivo como CSV (UTF-8) y subilo. Se crearán solo las filas válidas; las demás se reportan con su motivo.

Formato de las columnas obligatorias:

  • tipo — uno de: {% for v in tipo_values %}{{ v }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • cliente_id — el ID interno de un cliente tuyo (ver la tabla de abajo).
  • tipo_mensura (opcional, solo si tipo=Mensura) — uno de: {% for v in tipo_mens_values %}{{ v }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • Los campos _num de la nomenclatura admiten solo números.

La plantilla descargada incluye estas indicaciones como comentarios (líneas que empiezan con #); el importador las ignora.
